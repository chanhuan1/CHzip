核心特性

全方位解决 NAS 用户解压过程中的分卷、乱码、大文件和安全性痛点。

全格式覆盖与分卷自动合并
支持 7Z、ZIP、RAR、TAR、GZ、BZ2、XZ、ZST、CAB、ISO、ARJ、LZH 等； 自动识别 .7z.001、.001、.z01、.part1.rar、.r00 等全系列分卷序列，右键首卷自动合并，缺卷时即时告警。
免解压文件树与选择性解压
打开几十 GB 的庞大压缩包无需全盘解压！秒级呈现包内完整目录树，支持关键字即时过滤与搜索。 可仅勾选目标文件或单个子文件夹进行「选择性解压」，极速省时省存储。
包内文件秒开预览
无需解压到磁盘，直接双击查看包内图片、文档或代码；内置图片缩略图瀑布流墙、 PDF 在线直读预览以及 20+ 语言语法高亮代码阅读器。
多代码页编码彻底告别乱码
内置 UTF-8、GBK（Windows 常见）、Big5（繁体）、Shift-JIS（日文）、EUC-KR（韩文）编码无缝切换； 智能识别文件名编码，解决老旧 Windows 压缩包在 Linux/NAS 下文件名变问号的痛点。
本地密码管理与用后即焚
常用解压密码本地保存，解压时一键填入；临时密码文件在执行后进行多次随机数据覆写再彻底删除， 杜绝内存或磁盘取证残留，保护隐私安全。
安全防护与后台静默任务
严密防范跨目录遍历（如恶意压缩包中的 ../../ 逃逸攻击）； 解压任务由独立后台 Worker 守护，浏览器关闭不中断，支持实时取消并自动清理未完成半成品目录。
完整性体检与坏文件归因
一键对压缩包做流式 CRC 体检（7z t），不写盘即可确认数据完好； 校验失败时列出疑似损坏的具体文件清单，多分卷包损坏不再靠猜，重新下载有依据。
压缩包注释查看与编辑
直接查看 ZIP / 7Z 包内注释（打包者留言、解压说明等），支持在应用内编辑回写， 无需借助其它工具。
任务中心与智能收尾
实时进度 + 预计剩余时间 + 最近 20 条历史记录；解压成功自动「拍平」同名外壳目录； 同名冲突 4 种策略（自动重命名 / 覆盖 / 跳过 / 保留较新）；权限异常可一键生成脱敏诊断报告。

安装与使用步骤

四步极速部署，从下载到右键解压只需 1 分钟。

1. 安装离线包

  1. 下载架构安装包
    在上方「下载中心」根据你的 NAS CPU 选择下载 x86_64 或 arm64 对应的 .fpk 文件。
  2. 应用中心手动安装
    登录飞牛 fnOS 桌面，进入「应用中心」→ 点击右上角「手动安装」→ 选择刚下载的 .fpk 上传。
  3. 安装完成
    系统会自动安装 Node.js 运行时环境依赖，并在桌面与启动台中生成「CHzip」应用图标。

2. 授予读写权限（关键）

  1. 进入应用设置
    打开飞牛「控制面板」或「应用中心」找到已安装的 CHzip，点击进入「应用设置」。
  2. 勾选存储权限
    在存储权限列表里，为 CHzip 勾选需要读取压缩包和解压输出的共享文件夹「读写」权限。
  3. 单文件夹临时授权
    若某个文件夹提示无权访问，也可在飞牛「文件管理器」中右键该文件夹 →「属性」→「权限」中新增应用权限。

3. 文件管理器右键使用

  1. 右键选中压缩包
    在飞牛「文件管理器」中，右键任意压缩包（分卷压缩包只需选中第一卷 .001 或 .part1.rar）。
  2. 使用 CHzip 打开
    在右键菜单中点击「使用 CHzip 打开」，即可调出交互式操作界面。
  3. 快速预览或解压
    选择目标输出路径，按需勾选指定文件或直接点「开始解压」，即可在后台享受极速解压。

常见问题解答 (FAQ)

关于安装、分卷识别与权限的常见疑问解答。

只需在文件管理器中右键选中第一个分卷（例如 xxx.part1.rar、xxx.7z.001、xxx.zip.001 或 xxx.001）并选择使用 CHzip 打开即可。 CHzip 会自动扫描同目录下匹配的后续所有分卷并无缝拼接解压。如检测到缺失某一分卷，界面会给出清晰友好的提示。
飞牛 fnOS 采用了严密的权限白名单保护。在飞牛桌面的「控制面板」或「应用中心」→「已安装应用」找到「CHzip」，点击「应用权限」并勾选你保存压缩包和解压输出目录的共享文件夹读写权限即可。
在 CHzip 解压界面中找到「代码页」下拉框，将默认的「UTF-8 / 自动」切换为「简体中文 GBK」（常见于早期 Windows 简中环境）或「繁体中文 Big5」，文件树中的文件名将实时转为正确中文，解压后也不会再出现乱码。界面检测到疑似乱码文件名时还会自动弹出切换建议横幅，一键即可换码页。
