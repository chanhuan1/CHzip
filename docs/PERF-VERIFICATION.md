## 二、改动范围

### 批次 2：解压吞吐（`app/server/lib/worker.js`、`engine.js`、`jobs.js`）

| 项 | 改动 |
|---|---|
| 进度回写节流 | 由「每个 7z 输出 chunk 都落盘」改为「距上次 ≥200ms 或百分比跳变 ≥1 才落盘」，phase 切换 / 进程结束 / 终态前强制 flush |
| 单一日志状态 | 解码器（StringDecoder）与进度解析合并进 `createProgressTracker`，删掉原先的双份 64KB 字符串拼接；chunk 边界切断多字节字符不再产生乱码 |
| `job.log` 只在终态落盘 | 热路径不再序列化最多 64KB 的日志；终态仍写一次日志尾部供事后诊断 |
| 增量进度解析 | `parseProgress` 由「每次重扫整段累积日志」改为增量（只处理新字节 + 当前行），并保持**逐字节等价**（已用 1/2/3/5/7/13 字节切分验证） |
| 列表校验进程内化 | 不再多起一个 node 子进程（原 `listing-validator.js`）+ 64KB JSON 往返；worker 直接 spawn 7z 并把 stdout 流式喂给 `createTechnicalListValidator`。**路径安全预检（拦 `..` / 绝对路径 / 盘符 / NUL）与各项长度上限完整保留** |

### 批次 3：前端轮询与渲染

| 项 | 改动 |
|---|---|
| 统一轮询器 | 三处 `setInterval` 改为递归 `setTimeout` + in-flight 守卫（任何时刻最多一个在途请求），消除请求堆积与乱序覆盖 |
| 页面隐藏降频 | 隐藏时降到 30s 一次，恢复可见时立即补一次 |
| 空闲退避 | 常驻任务监听由「永远 5s」改为 5s → 15s → 30s 阶梯，有任务时 1.5s |
| 请求超时 | `requestJson` 支持超时与 `AbortController`；默认 5.5 分钟（与后端 5 分钟对齐），轮询类可传更短 |
| 密码库读缓存 | `password-store.read()` 加内存缓存（写成功即失效），勾选文件不再触发全量 AES-GCM 解密；密码状态文本做「值未变不写 DOM」短路 |
| 大文本预览 | `escapeHtml` 改为纯字符串替换（原先**每行创建一个 DOM 元素**）；渲染行数上限 20000、高亮行数上限 3000，超出部分给出提示 |
| 图片预览解码 | 逐字符 JS 循环改为原生 `Uint8Array.from` |
| 文件树 | 选中计数由 O(节点数 × 深度) 改为一次后序预聚合 O(节点数)；可见节点分批渲染（每批 200，按帧补齐）；逐节点监听改为容器级事件委托；勾选只做定向复选框刷新，不再整树重建 |
| 任务流 | 按 `job.id` 复用行，轮询时只改文本；任务中心增加渲染签名短路（数据未变不重建 DOM） |
| 脚本加载 | index.html 的 12 个 `<script>` 加 `defer`（保持原有相对顺序） |

### 重点观察项（对应本次收益）

- **第 4 条**是本次最大收益点：进度回写从「每 chunk 一次全量落盘」变成「≤5 次/秒」，
  且热路径 payload 从 ~64KB 降到 <1KB。若解压时间没有改善，请回传 `iostat`/`top` 采样。

- **第 15 条**是顺带修掉的正确性 bug：原先 worker 被强杀后任务会永久卡死。

## 四、明确未做的项（含理由）

| 项 | 理由 |
|---|---|
| 移除 7z 的 `-bb1` 参数 | 需要先在真机确认「只用 `-bsp1` 时进度行仍带文件名」，否则「正在处理」会退化成空。**建议先在 NAS 上跑** `7zzs x -bsp1 ...` 与 `7zzs x -bsp1 -bb1 ...` 重定向 stdout 对比，确认后再改。属于"零收益风险、必须实测"的项，本轮不动 |
| 静态资源长缓存（`?v=` 生效） | 交接文档已记录「fnOS 内嵌窗口可能跑旧缓存」是历史痛点；把 JS 从 `no-store` 改成长期缓存会让这个问题更难排查。收益仅限页面打开时，风险不对称，故不动 |
| 长轮询 / SSE、CGI 改常驻服务 | 属架构级改造，已确认排除 |
| 嵌套 tar 外层只解一遍 | preview 与 worker 分属不同进程/临时目录，共享需跨进程传递所有权，属架构级 |
| 文件树虚拟滚动 / 分页 | 需重写树交互，工作量大；分批渲染 + 定向更新已覆盖主要卡顿来源 |
| 任务中心完整 keyed diff | 已做「数据未变不重建」短路；完整 diff 需拆分 section 容器，收益（弹窗打开时每秒约数百次 DOM 操作）与风险不成比例 |
| `searchFiles` 的 `toLocaleLowerCase` | 改 `toLowerCase` 会改变非 ASCII 文件名的匹配语义，收益低、风险非零 |

## 五、已知行为变更（需确认是否接受）

1. **大文本预览会截断显示**：超过 20000 行只渲染前 20000 行（并给出提示），
   高亮只做前 3000 行。复制按钮仍复制完整内容。这是为了避免主线程假死。
2. **页面隐藏时轮询降到 30s 一次**（不是完全停止）。刻意不彻底停止：fnOS 内嵌窗口对
   `document.hidden` 的上报无法在本地验证，若它误报为 true，彻底停止会让界面永久不更新。
3. **勾选文件后不再整树重绘**，只更新受影响的复选框；视觉效果一致。
4. **`?v=` 缓存键仍然不生效**（JS 依旧是 `no-store`），维持现状。
